# 공부킬러 (Study Killer)

사진으로 공부 자료를 등록하고 AI가 요약·핵심 용어·복습 포인트·퀴즈를 생성하는 한국어 웹앱 스타터 프로젝트입니다.

## 포함 기능

- 사진 최대 6장 업로드
- 브라우저 OCR(Tesseract.js, 한국어/영어) 시도 + 사진 자체를 AI 모델에 전달
- Gemini API로 자료 요약, 핵심 용어, 복습 포인트, 객관식 문제 생성
- 문제 수 10~100개, 10개 단위 선택
- 정답 및 해설, 점수/정답률 표시
- 오답 복습 목록 및 복습 완료 표시
- 학습 자료/기록을 브라우저 localStorage에 저장
- API 키는 서버 `.env`에 보관, 요청 제한 및 업로드 파일 크기 제한

## 실행 방법 (Windows)

1. Node.js LTS를 설치합니다: https://nodejs.org/
2. 이 폴더에서 터미널/PowerShell을 엽니다.
3. 아래 명령을 실행합니다.

```powershell
npm install
Copy-Item .env.example .env
```

4. `.env` 파일을 열어 `GEMINI_API_KEY`에 본인의 키를 입력합니다. 키 발급: https://aistudio.google.com/apikey
5. 서버를 실행합니다.

```powershell
npm start
```

6. 브라우저에서 http://localhost:3000 을 엽니다.

## 무료 이용 관련

Gemini API는 일부 모델에서 무료 등급을 제공하지만, 사용량 한도·모델 제공 여부·지역별 조건은 바뀔 수 있습니다. AI Studio에서 현재 프로젝트의 한도를 확인하세요. 무료 등급은 데이터 사용 조건을 반드시 확인하고, 민감하거나 개인적인 자료는 올리지 마세요.

Tesseract.js는 브라우저에서 OCR을 시도합니다. 한국어 OCR 데이터가 처음 로드될 때 인터넷 연결이 필요할 수 있고, 손글씨·흐릿한 사진·수식은 정확도가 낮을 수 있습니다. 이 앱은 OCR 결과와 이미지 자체를 함께 AI에 전달합니다.

## 중요한 제한 사항

- AI 문제 수가 요청한 개수보다 적으면 현재 앱은 생성된 문제를 반복해 선택한 수를 맞춥니다. 반복 문제는 화면에 표시됩니다. 서로 다른 문제만 필요하다면 충분한 분량의 자료를 제공하고, 서버 프롬프트/검증 로직을 강화해야 합니다.
- 단답형 문제 유형 UI는 제공되지만, 현재 서버는 안정성을 위해 객관식 문제를 생성합니다. 실제 단답형 자동 채점은 정답 변형·유사 표현을 판정하는 별도 로직이 필요합니다.
- 자료/오답 저장은 현재 브라우저에만 됩니다. 로그인, 기기 간 동기화, 클라우드 데이터베이스는 포함하지 않았습니다.
- 실제 공개 배포 전에는 로그인, 악용 방지, 비용 한도, 개인정보 처리방침, 서비스 약관, API 사용 정책 검토가 필요합니다.
- 사진은 AI 분석을 위해 서버로 전송됩니다. 서비스 이용자에게 업로드/전송 사실을 명확하게 안내하세요.

## 배포

Node.js를 지원하는 호스팅에 배포하고 `GEMINI_API_KEY`를 호스팅의 환경변수로 등록합니다. API 키를 HTML이나 `public/app.js`에 넣지 마세요.
